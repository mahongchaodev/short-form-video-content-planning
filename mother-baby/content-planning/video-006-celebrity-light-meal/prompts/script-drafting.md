# Agent Prompt：明星轻食早餐拆解脚本

## 任务目标

生成一条“明星轻食早餐怎么借鉴”的短视频脚本，强调只学搭配逻辑、不抄菜单。

## 输入上下文

- 栏目：明星养生之道拆解。
- 目标受众：容易被明星餐盘种草的家庭用户。
- 核心方法：搭配逻辑、同类替换、个人边界。
- 边界：不做营养处方，不宣称减脂、排毒、调理等效果。

## 执行要求

1. 开头明确“别急着照抄菜单”。
2. 用三看卡组织内容，避免复刻明星菜单。
3. 特殊人群边界必须清楚。
4. 输出口播、镜头建议、字幕、CTA 和置顶评论。

## 输出格式与验收

按“钩子 / 三看卡 / 边界提醒 / CTA”输出。验收标准：可用桌面卡片和食物示意完成，不包含功效承诺。
