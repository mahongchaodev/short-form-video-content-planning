# Agent Prompt：母婴视频脚本初稿

## 任务目标

为一个母婴主题生成可拍摄的短视频脚本初稿，并保留适用范围与信息边界。

## 输入上下文

- 账号定位：为孕产期和育儿阶段家庭提供清晰、可执行且尊重个体差异的信息。
- 视频选题：<填写具体场景>
- 目标受众与阶段：<填写>
- 可靠来源或个人经验边界：<填写>

## 执行要求

1. 开场从目标人群的具体场景切入，不制造焦虑。
2. 明确建议的适用阶段、限制条件及需要咨询专业人士的情况。
3. 输出口播、镜头建议、字幕重点和收藏/关注 CTA。

## 输出格式

按“场景钩子 / 方法或经验 / 适用边界 / CTA”四段输出；不能补造医学结论或虚构来源。
