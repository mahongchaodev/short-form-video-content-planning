# Agent Prompt：母婴视频脚本初稿

## 任务目标

为“名人养生内容怎样不盲从”生成可拍摄的母婴短视频脚本初稿，并保留适用范围与信息边界。

## 输入上下文

- 账号定位：为孕产期和育儿阶段家庭提供清晰、可执行且尊重个体差异的信息。
- 视频选题：借“孙俪式养生”话题，展示来源、个人阶段和低成本尝试三关。
- 目标受众与阶段：对明星养生内容感兴趣、处于孕产或育儿早期的家庭。
- 可靠来源或个人经验边界：拍摄前核验本人认证账号或正式访谈的原始内容；个人公开分享不是健康处方，个体问题咨询专业人士。

## 执行要求

1. 开场从“看到名人养生就想一键照抄”的场景切入，不制造焦虑或暗示效果。
2. 用“原始来源、我的阶段、低成本尝试”三关组织；不复述或推广未经核验的名人主张。
3. 明确个人经验不能替代健康建议；产后恢复、用药、哺乳或不适时应咨询专业人士。
4. 输出口播、镜头建议、字幕重点和收藏/关注 CTA。

## 输出格式

按“场景钩子 / 三关判断 / 适用边界 / CTA”四段输出；不能补造医学结论、虚构名人来源或儿童隐私。验收标准：脚本可在 55 秒内用口播和桌面卡完成。
