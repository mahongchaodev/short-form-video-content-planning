# Agent Prompt：名人轻食内容判断视频脚本

## 任务目标

生成一条 55 秒内短视频脚本，借名人妈妈公开的轻食、早餐或饮食记录，介绍不盲从食谱的三看判断卡。

## 输入上下文

- 目标受众：看到名人妈妈饮食内容容易被种草、处于孕产或育儿早期的家庭。
- 三看：完整上下文、个人阶段与限制、是否简单可持续。
- 内容边界：个人饮食记录不是营养处方；不宣称排毒、减重或调理效果，孕产、哺乳、过敏、疾病或用药问题咨询专业人士。

## 执行要求

1. 钩子表达“看到一餐轻食别急着照抄菜单”。
2. 每个判断点以一张可保存的卡片呈现，避免说教和绝对化表达。
3. 拍摄前核验可引用的原始公开来源，并明确饮食个体差异和专业咨询边界。
4. 输出口播、桌面镜头、字幕、CTA 和置顶评论。

## 输出格式与验收

按“场景钩子 / 食谱三看 / 适用边界 / CTA”输出。验收标准：脚本可由一个人用桌面卡拍摄，不含儿童与家庭识别信息，也不将个人饮食记录包装成专业结论。
