# 第 001 期：建立可信的母婴与养生内容框架

## 本期目标

- 周期：建议在 7 天内发布 3 条，间隔 1–2 天；每条发布 48 小时后记录收藏、转发和具体场景评论。
- 主目标：验证“名人公开养生内容 + 三步判断卡”能否带来收藏，同时建立不盲从、不制造健康焦虑的可信表达。
- 目标受众：备孕、孕产与 0–12 个月婴儿家庭，及希望建立低压力健康生活方式的家庭成员；兼顾祖辈和伴侣。
- 核心指标：优先观察收藏、转给家人的比例、能否引出具体家庭场景；不以焦虑、囤货或效果保证驱动互动。

## 本期发布节奏

1. **视频 001（名人养生判断）**：借孙俪式养生话题，先教观众判断来源、阶段和低成本尝试。
2. **视频 002（名人运动判断）**：借陈意涵的运动形象，先建立“动力不等于恢复方案”的边界。
3. **视频 003（名人食谱判断）**：从明星妈妈公开轻食内容切入，教观众别把一餐菜单当成养生答案。

## 内容边界检查

- 名人的生活方式公开分享只作为话题入口，拍摄前必须登记原始公开链接、发布时间、截图范围和使用限制；找不到原始来源就去掉姓名。
- 不使用“同款即有效”“跟着做就能恢复”等效果暗示，不拿产后身材、体重或恢复速度作比较；成人轻养生内容不外推为儿童做法，涉及健康、营养、运动的个体问题建议咨询专业人士。
- 不展示儿童可识别面部、姓名、住址、健康记录或就诊信息；现场素材优先用判断卡、桌面和示意图。
