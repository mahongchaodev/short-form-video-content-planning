# 第 001 期：母婴和养生四大栏目起号测试

## 本期目标

- 周期：建议 7 天内发布 4 条，前 4 天连续测试，后 3 天复盘并追拍表现最好的一类。
- 主目标：验证四个固定栏目中，哪一类最容易带来收藏、评论追问和系列化空间。
- 目标受众：0–3 岁婴幼儿家庭、新手爸妈、参与照护的祖辈，以及关注家庭养生饮食的人。
- 核心指标：收藏率、评论中的具体需求、转发给家人比例；不以焦虑、夸大功效或强带货驱动互动。

## 本期发布节奏

1. **视频 001（婴幼儿美食制作和教学）**：做一份新手友好的宝宝蔬菜蛋羹，测试“可跟做”收藏。
2. **视频 002（婴幼儿好物推荐）**：讲宝宝餐椅怎么选，测试“购买判断标准”收藏。
3. **视频 003（养生知识分享）**：讲“养生不是越补越好”，测试“误区纠偏”互动。
4. **视频 004（养生食物制作教学）**：做一碗家常小米南瓜粥，测试“家庭养生食谱”跟做。

## 内容边界检查

- 婴幼儿美食只做一般制作教学，不替代儿科医生、营养师或个体化喂养建议；月龄、过敏、吞咽能力和家庭实际情况必须提示。
- 好物推荐必须说明“适合场景”和“不适合情况”，不使用“必买”“闭眼入”等绝对化表达。
- 养生知识和养生食物不承诺治疗、调理、减肥、排毒等效果；慢病、孕产、用药或不适人群建议咨询专业人士。
- 不展示儿童可识别面部、姓名、住址、健康记录或就诊信息。

## 本期素材与提示词

每条视频独立维护自己的 `assets/` 和 `prompts/`；食材、用品和生活方式做法仅作家庭场景示例，不作功效保证或强制购买推荐。
