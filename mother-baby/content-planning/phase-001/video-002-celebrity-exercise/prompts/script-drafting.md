# Agent Prompt：名人运动内容判断视频脚本

## 任务目标

生成一条 55 秒内的短视频脚本，借陈意涵的运动形象切入，介绍新手妈妈看名人运动内容时的三问判断卡。

## 输入上下文

- 目标受众：刷到明星运动内容、想恢复活动习惯的新手妈妈和家人。
- 三问：恢复阶段与专业建议、今天身体感受、是否低强度且可随时中断。
- 内容边界：不示范动作、不推荐运动量或恢复节奏；产后恢复、疼痛、哺乳或既往健康问题建议咨询专业人士。

## 执行要求

1. 开头呈现“看见明星运动就想跟练”的比较压力，不评价任何人的身材或恢复速度。
2. 明确公开内容只能提供动力，不能替代个人恢复方案。
3. 拍摄前核验可引用的原始公开来源；所有建议保持为一般边界，不出现儿童隐私。
4. 输出口播、三问卡、边界字幕、CTA 和置顶评论。

## 输出格式与验收

按“场景钩子 / 三问判断 / 适用边界 / CTA”输出。验收标准：视频不包含个体化运动建议，观众可直接保存三问卡。
