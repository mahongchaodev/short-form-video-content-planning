# Agent Prompt：明星运动自律拆解脚本

## 任务目标

生成一条“明星运动自律怎么普通家庭借鉴”的短视频脚本，强调降低强度和频率，不照抄训练量。

## 输入上下文

- 栏目：明星养生之道拆解。
- 目标受众：看到明星运动自律后想跟练的家庭用户。
- 核心方法：身体反馈、低强度可中断、家庭条件。
- 边界：不提供训练方案；孕产、慢病、疼痛、用药或不适人群咨询专业人士。

## 执行要求

1. 开头强调“别先抄强度”。
2. 不示范具体动作，不给训练量。
3. 用三问卡输出普通家庭可判断的借鉴方法。
4. 输出口播、镜头建议、字幕、CTA 和置顶评论。

## 输出格式与验收

按“钩子 / 三问判断 / 专业边界 / CTA”输出。验收标准：不制造身材焦虑，不将明星经验包装成运动处方。
