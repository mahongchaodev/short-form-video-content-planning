# Agent Prompt：明星养生日常三关判断脚本

## 任务目标

生成一条“明星养生日常能不能照抄”的短视频脚本，帮助普通家庭用三关判断法决定是否借鉴。

## 输入上下文

- 栏目：明星养生之道拆解。
- 目标受众：关注明星养生日常、但担心不适合自己的家庭用户。
- 核心方法：原始来源、个人阶段、低成本动作。
- 边界：不做医疗、营养或运动处方；找不到原始公开来源不点名。

## 执行要求

1. 开头用“别一键照抄”制造反差。
2. 三关必须具体、可保存、可复用。
3. 明确明星公开生活方式不是通用健康方案。
4. 输出口播、镜头建议、字幕、CTA 和置顶评论。

## 输出格式与验收

按“钩子 / 三关判断 / 专业边界 / CTA”输出。验收标准：60 秒内讲完，避免八卦化和功效化表达。
