## 发布与复盘规则

- 婴幼儿美食只做一般制作教学，不替代儿科医生、营养师或个体化喂养建议；月龄、过敏、吞咽能力和家庭实际情况必须提示。
- 好物推荐必须说明“适合场景”和“不适合情况”，不使用“必买”“闭眼入”等绝对化表达。
- 养生知识和养生食物不承诺治疗、调理、减肥、排毒等效果；慢病、孕产、用药或不适人群建议咨询专业人士。
- 不展示儿童可识别面部、姓名、住址、健康记录或就诊信息。

新增视频时在 `content-planning/` 下创建 `video-<nnn>-<slug>/`，并同步更新本表。
